## Featured Build: CrediClip

**AI-powered credibility analysis for TikTok, Instagram Reels, and YouTube Shorts**

Short-form videos often spread faster than viewers can verify them. I built CrediClip as a 0-to-1 capstone product that converts a public video link into a credibility score, risk signals, evidence coverage, and claim-level notes.

- **My role:** Product Owner and Builder, from problem definition and workflow design through prototyping, testing, deployment, and technical documentation
- **System:** FastAPI control plane, SQLite-backed job queue, platform-specific worker lanes, OCR/ASR extraction, browser-assisted recovery, heuristic scoring, and LLM-supported analysis
- **Engineering focus:** Separating lightweight request handling from resource-intensive evidence collection so one platform's failures do not block the full pipeline
- **Output:** Compact credibility results covering misinformation, scam, AI-content, manipulation, confidence, and evidence quality
